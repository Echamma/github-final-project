# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements,
enhancements, and ideas are welcome.

## Ways to Contribute

- **Bug reports** - tell us what went wrong, what you expected instead, and the
  exact input values you used
- **Bug fixes** - corrections to the calculation logic, input handling, or output
  formatting
- **Documentation improvements** - clearer wording, better examples, fixed typos
- **Enhancements** - new options such as compound interest, currency formatting,
  or non-interactive command line arguments
- **Ideas** - open an issue to discuss a change before writing code

## Reporting a Bug

Open an issue and include:

1. The principal, rate of interest, and time period you entered
2. The output you received
3. The output you expected
4. Your shell and operating system

## Submitting Changes

1. Fork the repository
2. Create a branch for your work: `git checkout -b my-change`
3. Make your change and test the script with a few sample inputs
4. Commit with a clear message describing what changed and why
5. Push the branch and open a pull request against `main`

## Code Style

- Keep the script POSIX-friendly Bash and runnable with `bash simple-interest.sh`
- Quote variables, and validate user input before using it in calculations
- Use two spaces for indentation and keep lines under 80 characters where practical
